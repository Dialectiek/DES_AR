Controls in AR

Corner setup

  • Trigger — place a corner where the cursor is (4 corners, any order)
  • Bumper — undo the last corner
  • No surface found for corner 1? Touch the corner with the controller tip and press the trigger.

Manual (after corner setup)

  • 1. Place: a palette lies along the table edge nearest to you. Trigger on a tile picks that asset; trigger on the table places it (as many as you like). Bumper = undo the last asset.
  • Trigger on "Done placing" — start connecting
  • 2. Connect: trigger on an asset, then on another connects them (again = disconnect). Bumper = undo the last connection; with none left it goes back to placing.
  • Trigger on "Done connecting" — finished: the flows keep running. Bumper = back to connecting.
  • Hold the bumper (1.5 s) — calibrate the table again (clears everything)

Colour cards (after corner setup)

  • Colour squares — lay one card in each square on the table, press the trigger
  • Trigger on a card — adds the asset for its colour
  • Trigger on an asset, then on another — connect them (again = disconnect)
  • Bumper — undo the last card or connection
  • Hold the bumper (1.5 s) — calibrate the table again (clears everything)

Diorama — appears after corner setup; hold the bumper to calibrate again.

Scenario timeline (diorama with a simulation scenario)

  • A timeline panel lies along the table edge nearest to you. Trigger on ▶ — play / pause; trigger on the chart — jump to that time
  • Bumper (short press) — play / pause
  • In ?preview=1: click the panel, Space = play / pause, ← / → = one time step

Asset names (demo scene, and camera detection)

  • Point at an asset + trigger — show or hide its name above it
  • Point at a name + trigger — drop down the rest of that asset's information; again to close

Camera detection

  • Trigger / pinch — detect the table again (or place the cube in fallback mode)
  • Bumper / grab — show or hide the camera debug view

Menu button — exit AR

URL options
  • ?debug=1 — start with the camera debug view visible (corner setup: shows the card colours of the last scan)
  • ?flipy=1 — flip the camera image if detection looks upside down
  • ?table=0.75 — fallback table height in metres above the floor
  • ?build=manual / cards / demo — choose what goes on the table
  • ?scenario=power-balance-b — the diorama shows a simulation scenario (assets/scenarios/index.json); ?scene=demo — a scene file
  • ?speed=0.67 — timeline speed in simulated hours per second; ?autoplay=0 — start paused
  • ?setup=corners / ?setup=detect — choose the table setup
  • ?preview=1 — demo diorama on a virtual table, no headset; ?preview=1&build=manual — try manual mode with the mouse (click = trigger, Backspace = bumper)
  • ?corner=0.1 — corner radius of the outline in metres (detect: default estimated, corners: default 0)
  • ?white=180 — fixed brightness threshold for "white" (default: automatic)
  • ?aa=0 — turn antialiasing off
  • ?xrcompat=0 — let three.js make its own (non-XR-compatible) GL context, for comparison
