Table Cube

Finds the white table in the headset's camera feed, outlines it and puts a cube in the middle.

Controls in AR

Corner setup

  • Trigger — place a corner where the cursor is (4 corners, any order)
  • Bumper — undo the last corner; after setup: calibrate again
  • No surface found for corner 1? Touch the corner with the controller tip and press the trigger.

Asset names (every setup)

  • Point at a name + trigger — drop down the rest of that asset's information; again to close

Camera detection

  • Trigger / pinch — detect the table again (or place the cube in fallback mode)
  • Bumper / grab — show or hide the camera debug view

Menu button — exit AR

URL options
  • ?debug=1 — start with the camera debug view visible
  • ?flipy=1 — flip the camera image if detection looks upside down
  • ?table=0.75 — fallback table height in metres above the floor
  • ?setup=corners / ?setup=detect — choose the table setup
  • ?corner=0.1 — corner radius of the outline in metres (detect: default estimated, corners: default 0)
  • ?white=180 — fixed brightness threshold for "white" (default: automatic)
  • ?aa=0 — turn antialiasing off
  • ?xrcompat=0 — let three.js make its own (non-XR-compatible) GL context, for comparison
